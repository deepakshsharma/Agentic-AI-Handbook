# Scenario-Based Code Catalog

This catalog gives every chapter a concrete scenario path and maps it to both the chapter-specific implementation and the reusable library companions. The machine-readable source is [`scenarios.json`](../examples/scenario-runner/scenarios.json).

## Runner

```bash
python examples/scenario-runner/run_scenario.py --list
python examples/scenario-runner/run_scenario.py --chapter 44 --show
python examples/scenario-runner/run_scenario.py --chapter 44 --execute --output /tmp/ch44.json
```

## Scenario authoring contract

Each additional scenario should contain:

1. a typed input or JSON scenario file;
2. documented CLI arguments;
3. deterministic or dry-run behavior;
4. bounded execution budgets;
5. structured JSON output;
6. at least one failure or escalation path;
7. a README explaining the libraries and extension points;
8. no embedded credentials or confidential values.
